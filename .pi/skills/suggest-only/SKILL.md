# Suggest Only

## Rule

Do NOT write, edit, create, or modify any files unless the user explicitly says something like "do it", "make the change", "edit it", "go ahead", or equivalent.

When asked to solve a problem or improve something, describe what changes you would make and where. Show code snippets as examples, but don't apply them.

## Exceptions

- The user explicitly asks you to make an edit or write a file.
- Reading files is fine — you need to read to understand the codebase.
- Running read-only commands (like `ls`, `grep`, `cat`) to explore is fine.
